# Marlon HQ look

A Claude app theme for Marlon's three companies: Craque Kits, PixelEffigy and Sandpoint Seventh-day Adventist Church. Each look takes its colors from the company's website and puts its logo mark, faint, in the corner of a slowly moving background. Type /craque, /pixel or /sandpoint to switch; the choice is remembered for the next session. Desktop and mobile apps only.

## Install

At the prompt of a Claude Code session:

```
/plugin install marlon-hq --marketplace marlonabreu76-design/claude-theme
```

From a shell:

```
claude plugin install marlon-hq --marketplace marlonabreu76-design/claude-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `marlonabreu76-design/claude-theme`, then Add plugin.
